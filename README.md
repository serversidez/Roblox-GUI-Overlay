
# Roblox-GUI-Overlay
A single-file Windows overlay that draws a Roblox-style in-game interface on top of **any

https://github.com/user-attachments/assets/73d2fdb4-0e15-4f2e-a782-ed52eebb6468

 application you click on**: the top bar, chat, player list, profile card, hamburger menu, Esc menu and avatar page. Everything that isn't part of the interface is click-through, so the app underneath keeps working normally.
